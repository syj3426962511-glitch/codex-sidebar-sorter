# Codex Sidebar Sorter marketplace fields

## Summary

Sort Codex projects and chats with seven modes, continuous alphabetical ordering, and an independent tray worker. English by default with twelve language options.

## Compatibility

Windows x64 and Ubuntu Linux x64 previews require a compatible, signed-in Codex Desktop on the same machine. The 1.4.3 Windows client lifecycle check used official Codex 26.1111.9265.0. Signed-in seven-mode Linux ordering was verified with 1.4.2 on Ubuntu 26.04.1 x64 and Codex 26.1111.21308.

## Known limitations

Intel and Apple Silicon Mac packages are installation previews. Signed-in 1.4.3 client ordering, distinct client-version replacement, and signed consumer distribution on Mac are pending.
