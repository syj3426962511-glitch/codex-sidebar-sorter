# Codex Sidebar Sorter

Use this skill with desktop companion **1.4.4**. Check the operating system, processor architecture, and exact Codex client version. Use the installer links and the verification details in [Platform compatibility](references/compatibility.md). Intel and Apple Silicon Mac packages are installation previews.

## Use the companion

1. Start a compatible, signed-in Codex Desktop client. Open the companion and select **Refresh**. A fresh installation opens in English.
2. Select the intended **Scope**. Leave **Keep names sorted A to Z** on for continuous ordering. For a different rule, choose the mode and review its preview.
3. Select **Apply to sidebar**, then check the order in the same Codex sidebar. If the list changes or the tool asks for a refresh, confirm the scope and preview before applying again.
4. Close the companion window for tray operation. Use **Open Sidebar Sorter** in the tray to return, or **Exit** to stop the worker.

## English example

Sort the chats in Research Plan by natural number so Task 2 appears before Task 10 and Task 20. Keep name ordering enabled for everyday use.

1. Start a compatible signed-in Codex Desktop client and open Codex Sidebar Sorter. Select **Refresh**.
2. Select **Research Plan** under **Scope**. These examples use fictional chat names.
3. Choose **Natural numeric order** for chats. Read the preview in this order: **Task 2**, **Task 10**, **Task 20**.
4. Select **Apply to sidebar** and verify the order in Codex. If the list changed since the preview, refresh and check the scope before applying again.
5. Turn on **Keep names sorted A to Z** to resume continuous alphabetical ordering. Close the companion window to leave the tray worker running.
