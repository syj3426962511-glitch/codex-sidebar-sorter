## Sorting and background use

Projects and project chats have separate sorting choices. Use Name A to Z, Name Z to A, Natural numeric order, Reverse natural order, Recently updated first, Oldest update first, or Manual order.

Keep names sorted A to Z enables continuous alphabetical synchronization for supported sidebar items. Closing the companion window leaves its worker and tray running. Open Sidebar Sorter and Exit are available from the tray.

## Apply the configuration

Open the installed Codex Sidebar Sorter companion and a compatible, signed-in Codex Desktop on the same Windows computer. Select Refresh and check the project and chat preview.

In the companion's language selector, choose Deutsch. Enable Namen automatisch aufsteigend sortieren. The companion saves the language choice and enables ascending-name ordering for projects and their supported chats.

Keep the Codex client running while the companion synchronizes its sidebar. Closing the companion window leaves the independent worker and tray running. Open Sidebar Sorter in the tray reopens the interface.

## Temporarily use natural numeric order

Select the named project in Scope. Choose Natürliche Zahlenfolge for its chats. Review the preview and apply the order to the sidebar.

Natural order places Item 2 before Item 10 and Item 20. Choosing this manual rule pauses continuous alphabetical sorting. Enable Namen automatisch aufsteigend sortieren again when you want continuous alphabetical order to resume.
