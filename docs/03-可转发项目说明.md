# Codex 聊天排序工具

本项目开发一个独立运行的桌面工具，将项目和对话的排序结果同步到 Codex 原有侧栏。默认自动保持名称升序，新增或改名后由后台继续重排。

界面提供中文和英文切换，保留名称升降序、数字自然升降序、最近更新优先、最早更新优先、手动排序七种方式，并提供搜索、范围选择、两级预览、拖动、移动按钮和还原预览。

图形界面和排序后台采用独立进程，关闭窗口后保留原生托盘及事件驱动后台。侧栏调整通过客户端现有本地工具执行，历史索引以只读方式读取。客户端接口、接入授权及索引结构的变化纳入版本适配。

当前 1.4.0 候选已经通过 Windows x64、macOS ARM64、Ubuntu x64 的界面与协议测试，使用 30 个虚构项目及 360 条虚构对话。Windows 安装候选已通过安装、运行中的旧版升级、设置保留、完整退出后重开及卸载验收。真实客户端验收继续进行，Mac 的 MCP 服务加载成功，原生侧栏请求仍被进程签名校验拒绝，Linux 真实侧栏同步仍待验收。

Windows 1.4.0 已交付自带运行时、图标、资源和完整源码的安装包，并完成本机覆盖升级。macOS 和 Linux 安装包继续以对应的真实客户端验收为前提，完整三平台源码及下载将在验收后公开。
