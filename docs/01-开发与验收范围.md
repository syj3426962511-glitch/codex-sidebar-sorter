# 多语言独立排序工具 1.4.1 候选

本项目由独立排序工具 1.2.2 继续开发，完整运行文件通过云端构建。

- 提供简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、意大利语、俄语和阿拉伯语共 12 个语言选项。默认跟随系统语言，切换后保存工具自身偏好。阿拉伯语采用从右到左布局。
- 项目列表和项目内对话默认名称升序，保留七种排序方式。
- 安装包包含运行时和资源，安装路径可自定义。
- 使用客户端原生排序接口，历史索引以只读方式打开。
- 客户端启动、关闭及升级后的普通入口属于云端验收范围。
- 功能与客户端重启验收在云端执行。办公搭子后续授权了本机排序软件同步升级，本机按该授权执行安装及运行状态核对。
- 源码先进入私有候选仓库，测试通过后公开并发布安装包。

当前仍在开发和验收，公开发布以云端最终回执为准。

## 2026年11月16日确认的完整交付

办公搭子已明确选择自动同步并持续保持名称升序。工具需要在新增项目、新增对话和改名后自动计算并应用新顺序，关闭窗口后继续后台运行。

分别交付 Windows、macOS、Linux 的安装包，安装包自带运行时和资源。三个系统均需测试实际程序及对应客户端，当前 1.3.0 Windows 候选与共享核心回归继续作为已有证据。

分享产物为可转发的项目说明与共享链接。正式开源与发布在新范围验收后执行。

当前已增加文件事件驱动、800毫秒合并触发、空闲等待及运行中安全停止的自动排序引擎，补充 macOS 和 Linux 的 Unix socket 传输。真实客户端端点接入测试先行，后续界面和安装包采用共享排序逻辑。

## 当前实现

三平台共享 Avalonia 界面，自动排序由独立后台进程执行。Windows 使用原生通知区菜单，macOS 使用 Cocoa 状态菜单，Linux 使用 Ayatana AppIndicator。关窗后图形进程退出，后台继续监听数据变化。手动与自动操作通过工具自己的 IPC 通道串行协调。

自动范围覆盖原生接口可重排的默认项目列表、Codex 项目内对话、置顶及自定义分区内对话。最近聊天的独立名称顺序、ChatGPT 项目内对话顺序和置顶项目的位置仍受当前原生接口范围限制。

Windows 1.4.0 已通过云端安装、运行中升级、偏好保留、完整退出后重开及卸载，并完成本机覆盖升级。macOS 的 MCP 服务加载成功，原生侧栏请求仍被 `untrusted-code-signing-identity` 拒绝。Linux 真实侧栏同步继续待验收，完整三平台封装与公开发布以真实客户端验收通过为前提。
