# Linux and macOS installation

Choose the installer under your target companion version on [GitHub Releases](https://github.com/syj3426962511-glitch/codex-sidebar-sorter/releases).

## Linux x64

Make the `.run` file executable and install it into your selected folder. The package includes the app runtime and native tray dependency set. Ubuntu 26.04.1 x64 has the published 1.4.2 authenticated evidence. Additional distributions receive separate acceptance.

[Linux install and removal commands](07-delivery.md#linux) · [Compatibility](04-compatibility.md)

## macOS

Mac installation previews are built for Intel x64 and Apple Silicon arm64. Choose the DMG matching your processor. Open it and use **Install Codex Sidebar Sorter.command** to select a destination, or copy the app bundle to your chosen Applications folder. Quit the companion before removing an app copied manually.

The preview has an ad hoc signature suitable for the cloud installation checks. Public Developer ID signing and notarization are pending. The Mac packages cover companion installation and background behavior with test data. Authenticated sorting in the original Mac Codex sidebar requires a supported client connection and remains open.
