# Codex Sidebar Sorter

An independent desktop companion for sorting projects and chats in a compatible Codex Desktop sidebar.

- Seven methods cover name, natural number, last update, and manual ordering.
- Continuous name sorting keeps supported items ordered after additions and renames.
- English is the default, with twelve available interface languages.
- Closing the window keeps the companion running in the tray.
