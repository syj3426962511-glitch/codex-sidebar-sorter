# Codex Sidebar Sorter product guide

Codex Sidebar Sorter previews and applies project and chat ordering in a compatible Codex Desktop sidebar. The companion runs independently, offers seven sorting modes, starts in English, and lets you select from twelve languages.

Begin with the [installer and user guide](07-delivery.md). Download from [GitHub Releases](https://github.com/syj3426962511-glitch/codex-sidebar-sorter/releases) and check the [platform and build matrix](04-compatibility.md).

## What the Agensi purchase delivers

Agensi delivers an optional English agent skill for selecting the correct package, showing how to set up automatic ordering, explaining the sort modes, and troubleshooting connection status. The listing price is USD 9.50 as a one-time purchase. Desktop installers are available separately through GitHub.

## Example request

> Help me sort projects alphabetically and order the chats in Research Plan by natural numbers. Show how to return to automatic name sorting afterward.

A companion user should preview **Task 2**, **Task 10**, and **Task 20** in that order, apply the preview, and use **Keep names sorted A to Z** to resume automatic alphabetical sorting. An agent with authorized desktop controls may guide or perform those steps with the user.
